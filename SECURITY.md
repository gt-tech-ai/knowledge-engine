# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities **privately** — do not open a public
issue for a security report.

Use GitHub's private vulnerability reporting for this repository
(**Security → Report a vulnerability**), or contact the maintainers directly. Include:

- a description of the issue and its impact,
- the affected version(s) / commit,
- steps to reproduce (a minimal proof of concept if possible).

You can expect an acknowledgement within a few business days. We will work with you on
a coordinated disclosure and credit you in the release notes unless you prefer to
remain anonymous.

## Supported versions

Security fixes target the latest released `vX.Y.Z` tag. Older versions are supported on
a best-effort basis.
